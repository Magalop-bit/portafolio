# Placeholder CV site

## Add your CV
Drop your file into this folder, named exactly `cv.pdf` (next to `cv.html`). Nothing else to edit.

## Deploy on GitHub Pages
1. Create a new repo (e.g. `cv-site`) and push these files to the root of the `main` branch.
2. In the repo, go to **Settings → Pages**, set source to `main` branch, `/ (root)`.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
4. Point your QR code at that URL (or at `.../cv.html` to go straight to the CV).

## Updating later
- Swap `cv.pdf` for a new version any time — same URL, no QR regeneration needed.
- Replace `index.html` once your real portfolio is ready.
